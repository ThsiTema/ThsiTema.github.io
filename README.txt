ARTEM KOTENKO — STATIC PORTFOLIO

Открыть на macOS:
1. Распакуйте архив.
2. Дважды нажмите index.html.

Публикация на GitHub Pages:
1. Скопируйте содержимое этой папки в корень репозитория ThsiTema.github.io.
2. Сделайте commit и push в ветку, из которой публикуется GitHub Pages.

Сборка не требуется. Сайт состоит из обычных HTML, CSS и JavaScript.
Все изображения и PDF используют относительные пути и работают при открытии
index.html с диска.

Локальный просмотр через HTTP:
  python3 -m http.server 8000
Затем откройте http://localhost:8000.

Проверки перед публикацией (без сторонних зависимостей):
  python3 tests/check_site.py
  node --check script.js
  node --test tests/navigation.test.cjs

Проверки валидируют локальные ссылки и ресурсы, якоря, атрибуты изображений,
наличие PDF и повторные изменения активного пункта навигации.
Они не заменяют визуальную проверку в браузере на телефоне и компьютере.
